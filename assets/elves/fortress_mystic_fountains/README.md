# Elven fortress mystic fountains (`ElvenCitadel`, `ModuleTag_DrawMysticFountains`)

Model `EBFMFount`, mesh `EBFMFOUNT1`, own texture `EBFortresK.tga` (from `EBFortress.tga`).
`Tier.STANDARD`. EA's eight half-round basins and swans stay whole in the
[fortress](../fortress/README.md) ring's window recesses; EA's water meshes `EBFMFOUNT2` and
`EBFMFOUNT3` are unchanged.

## What changed

- **Coping**: rounded silver, along each basin's lip from wall to wall.
- **Crystals**: small starlight crystals in gilt cups at the coping's ends, below the swans' heads.
- **Pool**: a closed crystal-glass sheet over each basin floor, so the pool reads as water.
- **Banners**: none.
